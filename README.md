# Bilibili Frame

一个轻量的 B 站视频截图扩展，适用于 Chrome / Edge。点击播放器上的相机按钮，即可下载当前视频帧，无需预览确认。

## 功能

- 按视频当前实际分辨率导出，不截入播放器控件。
- 支持 PNG、JPEG、WebP；默认 PNG 无损，JPEG / WebP 质量默认 85%，可分别调整。
- 字幕与弹幕可分别选择是否包含，默认均开启。
- 支持普通播放与全屏，提供一键下载按钮和快捷键。
- 文件名自动包含视频标题、视频 ID 和时间点。
- 设置保存在本机，不上传视频或截图。

## 安装

1. 打开 [Releases 下载页面](https://github.com/augusdin/bilibili-frame/releases/latest)，展开 **Assets**，下载 `bilibili-frame-v版本号.zip` 安装包，而不是下方自动生成的 `Source code`。
2. 解压 ZIP，将里面的 `bilibili-frame` 文件夹放到一个长期保留的位置。安装后不要删除或移动它，浏览器会直接读取这个目录。
3. 在浏览器地址栏输入：Chrome 为 `chrome://extensions`，Edge 为 `edge://extensions`。
4. 开启「开发者模式」，点击「加载已解压的扩展程序」。
5. 选择 `bilibili-frame` 文件夹：打开这个文件夹应直接看到 `manifest.json`，不要选择 ZIP 文件或它的上一级目录。
6. 确认扩展列表出现 **Bilibili Frame**，然后刷新已经打开的 B 站视频页。
7. 播放视频，将鼠标移入播放器，点击底部相机按钮即可下载。也可以在浏览器工具栏的扩展菜单中固定 Bilibili Frame，方便打开设置。

无需构建或安装 npm 依赖。此项目通过 GitHub 分发，尚未上架浏览器扩展商店。

### 安装后没有按钮？

- 确认扩展已启用；首次安装后需要刷新视频页，仅重新打开设置窗口不会生效。
- 先让视频正常播放，再将鼠标移入播放器显示控制栏。
- 若提示找不到 `manifest.json`，请检查选择的文件夹层级。
- 若浏览器受公司或学校管理、不允许加载扩展，请联系管理员，不要关闭浏览器安全防护。

## 使用

**选好画面 → 点击播放器底部相机按钮 → 自动下载**

鼠标移入播放器，相机按钮位于底部清晰度按钮附近。想精确保存某一帧时，可先暂停视频。

- 点击浏览器工具栏中的扩展图标，调整格式、质量、字幕和弹幕选项，设置自动保存。
- 快捷键：Windows / Linux 为 `Alt+Shift+S`，macOS 为 `Option+Shift+S`。
- 图片保存到浏览器下载目录下的 `Bilibili Frames` 文件夹。

## 注意事项

- 「包含字幕 / 弹幕」只合成播放器**当前显示**的内容，不会自动开启字幕轨或弹幕。视频内嵌的文字始终保留。
- 普通文字弹幕可导出；点赞贴纸、头像、高级弹幕动画和防挡遮罩暂不保证完整还原，文字样式也不保证逐像素一致。
- PNG 为无损格式，不支持百分比画质设置；JPEG / WebP 的质量百分比不代表固定压缩率。
- 跨域限制、受保护视频及特殊播放器可能无法截图，不绕过网站访问限制。导出清晰度取决于当前加载的视频画质。
- 扩展仅申请本地存储和下载权限，内容脚本仅在指定 B 站域名运行。请尊重视频版权，仅保存和使用有权使用的内容。

## 开发

需要 Node.js 18 或更新版本。运行单元测试：

```sh
npm test
```

图标已随源码打包。如需重新生成：

```sh
npm ci
node scripts/icons.cjs
```
